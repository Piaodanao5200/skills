# 决策规则速查 — 西门子 S7-1200 可编程控制器系统手册

| 能力 | 一句话规则 |
|---|---|
| 功率预算核算与供电选型 | 先查 CPU 5V/24V 预算，逐项累加模块与 I/O 需求，差额<0 即须加独立外部电源（不得并联、仅共 M）。 |
| 用户程序结构决策（OB/FC/FB/DB） | 需跨扫描保存状态且多实例用 FB+背景DB；纯运算用 FC；事件入口用对应 OB；先模块化再线性，并核对 16/6 层嵌套。 |
| 数据一致性保障 | CPU 只保证单值原子；多值用 DIS_AIRT→读写→EN_AIRT 包临界区，传参走引用且优化设置一致，I/O 用 PIP 且必须绑 OB。 |
| 通信协议选型与组态 | 先定协议与角色再组态连接；PROFINET 先分配设备名，Modbus 先定主从与功能码，RS485 仅两端端接，PUT/GET 须显式启用。 |
| 在线诊断与故障排查 | 先转在线取证：LED 判大类、诊断缓冲区看最新条目；按事件→OB 映射判断行为，用诊断指令按粒度递进定位，处置后验证 LED 与缓冲区。 |
| 存储卡、固件与出厂复位维护 | 分清卡用途并确认 CPU 空闲后再操作；固件全程保持 24V，复位保留 IP 决策；不可逆动作须先告知并验证。 |
| 设备更换与版本兼容检查 | 确认 V3.0→V4.2 方向不可逆并归档项目；整项目升级 STEP7 不复制粘贴；逐项核对密码/OB/TO/HMI/DB 预留区，解除保护后重编译下载。 |
| 扫描周期、实时性与中断组态 | 用写输出→读输入→执行→通信模型估延迟；超时首次记诊断、同周期二次STOP；循环/硬件/延时中断按规则组态，DIS_AIRT/EN_AIRT 同链配对。 |
| 程序下载、调试与在线同步 | 下载前判容量/I/O 兼容；在线离线不一致先比较再决定上传或覆盖；监视/修改/强制分开用；RUN 下载先评估安全并知残留行为。 |
| 高速计数 / PID / 运动控制工艺组态 | 脉冲频率超扫描速率用 HSC；PID 放循环中断 OB 取恒定采样；开环用 PTO、闭环用 PROFIdrive；模拟量先 NORM_X 再 SCALE_X。 |
| 数据类型与寻址规则 | SCL 绝对地址加 %；立即访问用 :P；按 8点/2字节分组；整数按范围选、浮点按精度选；需绝对寻址的 DB 改标准访问。 |
| 安装接线与安全兜底规范 | 环境防尘隔离留 25mm；接线前断所有电源并配独立急停；单点接地 M 共点；灯负载加浪涌限制、感性负载加抑制；拿放板卡防静电。 |
| PLC 系统设计七步流程 | 按分区→功能规范→安全电路→系统安全→操作员站→组态图→符号表七步走，安全回路必须前置于程序，且只覆盖正常与预期异常。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
