# 安装接线与安全兜底规范

## R — 原文 (Reading)

> "警告：S7-1200 安装不当会导致发生电气故障或出现意外的机械操作……必须遵守适当操作环境的所有安装和维护说明以确保设备安全运行。" "警告：安装已上电的 S7-1200 或相关设备或者为这些设备接线可能会导致电击或意外设备操作……如果没有断开所有电源……" "警告……应使用紧急停止功能、机电超控功能或其它独立于 S7-1200 的冗余安全功能。"
>
> — Siemens AG，《S7-1200 可编程控制器系统手册》V4.2，ch4.1 p59；ch4.4 p81；ch7.1 p199

## I — 方法论骨架 (Interpretation)

这一能力把"把 PLC 装进柜子、接上电和线"这件事变成可逐条核对的硬规则清单，核心是防两类事故：电气故障和受控设备的意外动作。环境上：开放式设备必须装在 IP54 之类封闭外壳内、仅授权人员开启；高压高噪声设备（变频器）必须与低压逻辑设备物理隔离，信号线不得与动力线同槽；散热靠自然对流，上下与前端各留至少 25mm，纵向安装温度上限再降 10°C。用电安全上：接线/接地前必须断开 PLC 及所有相关设备的电源并锁定挂牌，且必须配独立于 PLC 的急停与机电超控——PLC 单点故障会同时击穿"检测—决策—执行"整条安全链，所以绝不能把 PLC 当唯一安全屏障。供电只能用合格隔离的 AC/DC 电源给 SELV 电路，非隔离/单绝缘电源会让本应可触摸的通信口带上危险电压。接地采用单点接地、地线短且≥2mm²。输出端：指示灯类负载浪涌电流是稳态 10–15 倍，要加插入式继电器或浪涌限制器；JM 感性负载必须跨接抑制电路（AC 用 MOV、DC 用二极管+稳压管，抑制元件靠近负载），否则高压瞬变损坏触点、高频噪声打断 PLC。静电敏感：拿放板卡/存储卡须接地垫或腕带。

## A1 — 应用示例 (Application Example)

### 示例 1: 包装机控制柜安装接线核对（合成演练）
- **类型与来源**: 合成演练——手册 ch4.1/4.4 给出规则（p59–87），未给完整项目；以下按规则复算，非作者亲历。
- **问题/输入**: 一台 S7-1200 与一台变频器同柜安装，PLC 继电器输出驱动接触器线圈和指示灯，柜内空间紧凑。
- **方法论的使用**: ①变频器与 PLC 分区、动力线与信号线分槽；②上下/前端留 ≥25mm，若柜高不足改纵向安装则温度上限按 10°C 降额重核；③接端子前断总电源并 LOTO，另设独立急停；④确认 AC/DC 电源为隔离型；⑤所有公共端单点接地、地线≥2mm²；⑥接触器线圈两端跨接抑制（AC 并 MOV/RC），指示灯回路串入可更换插入式继电器或浪涌限制器。
- **结论**: 得到一份可逐项打勾的安装接线核对表，全部硬规则满足。
- **结果**: 演练输出与手册规则一致；实际柜体运行结果未说明。

### 示例 2: 感性负载抑制（worked_example）
- **类型与来源**: 原书规则示例，ch4.4 p85–86；失败模式见 ce13。
- **问题/输入**: 继电器输出驱动 24V 接触器线圈，断开线圈时产生反电动势尖峰。
- **方法论的使用**: DC 线圈两端反向并联续流二极管（或二极管+稳压管），且抑制元件紧靠线圈。
- **结论**: 尖峰被钳位，避免触点烧蚀与噪声耦合进 PLC。
- **结果**: 手册警告"只用 MOV 不加 RC 反而引入显著高频噪声"，故 DC 场景不单独用 MOV。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个能力?
1. 规划控制柜布局：PLC、变频器、电源怎么摆，留多少散热间距。
2. 现场要接线/接地/插拔模块，问安全前提和施工规范。
3. 输出带灯泡/接触器线圈，问要不要加抑制、加哪种。
4. 做过安装完成后想逐条核对有没有遗漏电气安全项。
5. 系统里出现"莫名其妙复位/干扰"，怀疑接线/接地/隔离没做好。

### 语言信号 (用户的话里出现这些就应激活)
- "控制柜怎么布局 / 安装间距" / "panel layout / clearance / 25mm"
- "接线前要不要断电 / 急停怎么配" / "lockout tagout / independent emergency stop"
- "感性负载要不要加抑制" / "inductive load suppression / flyback diode / MOV"
- "接地怎么接 / 单点接地" / "grounding / single-point ground"
- "防静电 / 存储卡拿放" / "ESD / grounding strap"

### 与相邻能力的区分（阶段 3 定稿）
- 与 `power-budget-sizing` 的区别：那边算"电够不够"，本能力管"怎么装、怎么接、怎么保安全"；先算预算再按本能力施工（composes-with）。
- 与 `device-replacement` 的区别：那边是版本升级/换型的兼容流程，本能力是物理安装与接线兜底；更换作业同时受本能力约束。
- 与 `storage-firmware-maintenance` 的区别：那边管存储卡/固件的操作流程，本能力负责其中"插卡前断电、防静电"的安全前提（composes-with）。

## E — 可执行步骤 (Execution)

**必需输入**: 安装方式（水平/纵向）；柜内是否有高压高噪声设备；负载类型（阻性/灯/感性线圈）；供电电源是否隔离；是否已配独立急停。缺失时先问，不得默认"已做"。
**交付物与完成标准**: 一份安装接线核对清单，分"环境/供电/接地/输出负载/静电"五组，每项标注"符合/不符合 + 依据页码"。

1. **环境与布局核对**
   - 完成标准：外壳 IP54+仅授权开启；高噪声设备与低压逻辑隔离、信号线与动力线分槽；上下/前端间距≥25mm；纵向安装已按 −10°C 重核温度。

2. **供电与用电安全核对**
   - 完成标准：接线前断开所有相关设备电源并 LOTO；配独立急停/机电超控；SELV 电路由隔离型 AC/DC 供电。
   - 判停条件：未配独立急停 → 停止后续带电作业，先补安全回路（ce10）。

3. **接地与电位核对**
   - 完成标准：所有公共端单点接地直连大地，地线短且≥2mm²；所有非隔离 M 端子接同一参考电位。

4. **输出负载抑制核对**
   - 完成标准：灯负载加插入式继电器/浪涌限制器；感性负载跨接抑制且靠近负载；DC 不用单一 MOV。

5. **静电与机械核对**
   - 完成标准：拿放板卡/存储卡已接地或戴腕带；未用工具强撬模块，扭矩未超限（CPU/SM 0.56 N·m、SB 0.33 N·m）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此能力
- 要算电源容量够不够——用 `power-budget-sizing`。
- 要做完整的七步系统设计（功能规范、操作员站、符号表）——用 `system-design-workflow`。
- 要查端子排订货号/针脚定义——走 reference-tables.md 检索。

### 作者在书中警告的失败模式
- **ce01**：安装环境不当（粉尘/潮湿/无隔离/无间隙）→ 电气故障或意外机械动作。
- **ce09**：带电接线 → 触电、短路、执行器误动。
- **ce10**：把 PLC 当唯一安全屏障 → 单点故障击穿整条安全链。
- **ce11**：非隔离/单绝缘电源给 SELV 电路 → 可触摸电路带危险电压。
- **ce12/ce13**：灯负载浪涌烧触点、感性负载缺抑制损坏输出并干扰 PLC。
- **ce05/ce06/ce08**：危险环境带电断开、徒手拿放 ESD、工具强撬/扭矩过大。

### 作者的盲点 / 时代局限
- 手册锁定 V4.2（2016），安装规范针对当时硬件；新 CPU/SB 的机械尺寸与扭矩须查新版。
- 假设读者具备电工素养与合规柜体；接地、抗干扰、网络拓扑等经验性知识不在书中。
- 功能安全与网络安全几乎缺席——"独立于 PLC 的急停"是原则性提示，不构成完整功能安全设计（如 failsafe 认证）。

### 容易混淆的邻近能力
- `power-budget-sizing`（容量核算）、`device-replacement`（换型兼容）、`storage-firmware-maintenance`（插卡安全前提）。

## 相关能力（阶段 3 填充）
